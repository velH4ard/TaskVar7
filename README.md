# Вариант 7

Учет домашней коллекции компакт-дисков.

Запуск на Windows: `run.bat` или класс `Main` в Java IDE.

Проверка: `gradlew.bat test`. Для Gradle нужен установленный JDK.

Данные хранятся в памяти, после выхода коллекция начинается заново.

`model` - данные диска и словарей, `repository` - список дисков, `service` - проверки и поиск, `controller` - меню.
